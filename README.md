# SleepyTime

SleepyTime is a FiveM resource designed to make players perform the sleep emote for 5 minutes. It prevents players from canceling the emote, shooting, punching, or accessing their inventory during this time. After the 5-minute period, the emote is automatically canceled, and the screen is darkened slightly to simulate sleep.

## Install

1. Download the SleepyTime resource from the GitHub repository.
2. Extract the downloaded file into your FiveM server's `resources` directory.
3. Add the following line to your server's `server.cfg` file:
   ```
   ensure SleepyTime
   ```

## Use

1. Players can start the sleep emote by typing `/sleep` in the chat.
2. The sleep emote will automatically cancel after 5 minutes, and the screen will be darkened slightly.
